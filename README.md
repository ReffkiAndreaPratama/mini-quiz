# MiniQuiz 🎯

MiniQuiz adalah aplikasi kuis interaktif berbasis web untuk menguji pengetahuan dalam tiga kategori: Pengetahuan Umum, Teknologi, dan Sains.

## ✨ Fitur
- 3 kategori kuis dengan 5 pertanyaan per kategori.
- Pilihan ganda dengan umpan balik langsung.
- Penjelasan singkat setelah menjawab.
- Skor akhir, jumlah jawaban benar, dan akurasi.
- Rekor terbaik per kategori menggunakan `localStorage`.
- Mode gelap dan terang.
- Tampilan responsif untuk desktop dan ponsel.
- Tanpa backend, database, atau API key.

## 🚀 Menjalankan
1. Unduh atau clone repository.
2. Buka `index.html` di browser modern.

Untuk pengalaman pengembangan, gunakan ekstensi Live Server di VS Code atau jalankan server statis lokal.

## 🧰 Teknologi
- HTML5
- CSS3
- JavaScript vanilla
- Browser `localStorage`

## 📁 Struktur
```text
mini-quiz/
├── index.html
├── style.css
├── script.js
└── README.md
```

## 🌐 Deploy gratis
Aplikasi ini dapat di-host sebagai situs statis melalui GitHub Pages, Cloudflare Pages, atau Netlify. Tidak membutuhkan server backend.

## 📝 Catatan
Skor terbaik dan tema disimpan di browser pengguna melalui `localStorage`; data tersebut tidak disinkronkan antarperangkat. Pertanyaan adalah contoh untuk demonstrasi dan dapat ditambah atau disesuaikan di `script.js`.
